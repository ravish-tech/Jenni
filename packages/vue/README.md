# `jenni-vue`

Vue 3 components (`JButton`, `JInput`, `JAppShell`, `JGrid`, `JDialog`, `JCommandPalette`, and 50+ more) built as zero-`<style>` SFCs directly over `jenni-core` semantic HTML and `@layer` CSS.

## Usage

```ts
import 'jenni-core/css';
import { JAppShell, JSidebar, JTopBar, JPage, JButton } from 'jenni-vue';
```
