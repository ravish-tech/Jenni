# `@jenni/react`

React 19 components (`Button`, `Input`, `AppShell`, `Grid`, `Dialog`, `CommandPalette`, and 50+ more) built with zero CSS-in-JS directly over `@jenni/core` semantic HTML and `@layer` CSS.

## Usage

```tsx
import '@jenni/core/css';
import { AppShell, Sidebar, TopBar, Page, Button } from '@jenni/react';
```
